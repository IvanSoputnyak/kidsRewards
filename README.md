# KidsRewards

A native SwiftUI iOS draft app for tracking kids' reward points locally on-device.

## Draft Scope

- No backend or network dependency.
- Data is stored locally using a JSON file in the app's documents directory.
- Configure:
  - Currency equivalent per point
  - Interest rate for vault deposits
  - Reward points per chore/task
- Track each kid's:
  - Available points
  - Vault points
  - Transaction history
- Actions:
  - Award points for configured work
  - Deposit points into the vault
  - Cash out available points at the current configured rate
  - Apply vault interest

## Open In Xcode

Open `KidsRewards.xcodeproj`, select an iPhone simulator, and run.

This is intended as a product and UX draft, not a production-ready app.
